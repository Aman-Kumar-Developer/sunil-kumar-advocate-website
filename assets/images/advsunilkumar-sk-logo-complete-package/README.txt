SK MONOGRAM LOGO PACKAGE

Source:
The supplied high-resolution SK monogram image.

All PNG logo files use a transparent background.

Files:
- sk-logo-master-2048.png  -> master high-resolution logo
- sk-logo-*.png            -> resized square PNG versions
- favicon.ico              -> multi-resolution browser favicon
- apple-touch-icon.png     -> Apple touch icon
- android-chrome-192x192.png
- android-chrome-512x512.png
- site.webmanifest         -> PWA icon configuration

Recommended website placement:
- Master/source: assets/icons/sk-logo-master-2048.png
- Header/web use: choose the smallest appropriate PNG
- Browser favicon: assets/icons/favicon.ico
- Apple touch icon: assets/icons/apple-touch-icon.png
